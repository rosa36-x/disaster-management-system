# Application Screenshot Guide

Capture screenshots from the running application with real project data. Keep the browser URL visible where practical and avoid exposing passwords, JWTs, or `.env` values.

Recommended screenshots for the final report:

1. Login screen.
2. Command-centre dashboard with live KPIs, supply-demand balance, and priority queue.
3. Incident report list with severity filtering.
4. Incident creation form and a successfully saved incident.
5. Field update form and saved field update.
6. Victim list and victim registration form.
7. Relief request list showing pending/matched/delivered states.
8. Batch matching result and delivery assignment list.
9. Depot, shelter, and supply inventory screens.
10. Restock action and updated quantity.
11. Vehicle and route management screens.
12. Role comparison showing different actions available to admin, logistics manager, and field worker.

Save the final images under `screenshots/` with descriptive names, for example `dashboard.png`, `incident-reports.png`, `request-matching.png`, and `supply-inventory.png`. Only capture states that were successfully tested.
